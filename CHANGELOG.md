# Changelog

## v0.3.2
- Moves spelling help into one central workspace directly above the keyboard.
- Adds three clear stages: Try, Jumble and Break it up.
- Jumble unlocks after the first incorrect attempt.
- Break it up unlocks after the second incorrect attempt and shows authored spelling chunks and pattern guidance.
- Jumble no longer reveals the full word after a successful build; the learner returns to an independent spelling attempt.
- Returning practice words can choose to be tested or go straight to Jumble help.
- Adds a visible Latest button that returns through the root launcher with a fresh query.
- Root launcher now appends a timestamp to the current release URL to reduce stale-version caching.

## v0.3
- Redesigns spelling help around challenge, learning and recall rather than revealing the answer.
- “Show me how” first gives a non-answer clue while keeping the spelling hidden.
- Adds an interactive jumbled-letter build activity for difficult words.
- Only shows spelling chunks and pattern guidance after the learner has successfully built the word.
- After building, hides the word again and asks for an independent spelling attempt.
- Returning practice words now ask “Think you've got it now?” with a choice to be tested or take a clue.
- Distinguishes normal first-try success, working a word out with help, and remembering a previously difficult word independently.
- Adds New / Learning / Remembering / Secure word-state logic behind the scenes.
- Practice words become secure after independent recall in later sessions rather than three immediate correct attempts.
- Adds a small challenge-star reward for persisting through a difficult word.

## v0.2.6
- Makes spelling “Check answer” the clear primary action with a large full-width button.
- Replaces small colour-only spelling feedback with prominent accessible feedback panels.
- Uses icons, headings, wording, border and background so feedback does not rely on red/green alone.
- Makes “Show me how” more prominent after an incorrect answer.
- Gives clearer prompts for empty answers and guided retries.

## v0.2.4
- Simplified Parent speech-speed setting to two choices: Clear and Normal.
- Clear is the default and recommended learning speed.
- Existing older speed choices fall back to Clear.
- Kept “Hear slowly” as the extra-slow spelling replay option.
- Added the ⭐ favicon.

## v0.2.3
- Voice clarity update for spelling and spoken help.
- Added actual device voice selector, with UK English voices listed first.
- Kept Female/Male preference for Automatic voice selection.
- Added parent speech-speed control, defaulting to a clearer 0.80 rate.
- Added Test Voice using a representative spelling word.
- Added “Hear slowly” during spelling practice.
- Renamed the generic sentence replay to “Hear in a phrase” and made it repeat the target word clearly.
- Improved Android/Chrome handling when speech voices load shortly after the page.
