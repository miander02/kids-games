# Learning Time v0.2

Reference version v0.1.3 remains unchanged in the previous folder/branch.

## Main changes
- First-use setup for child name and school year.
- Parent settings can independently multi-select Maths and Spelling working years.
- Year 2, Years 3/4 and Years 5/6 spelling libraries embedded from supplied text lists.
- Weekly School Spellings remain separate from the built-in libraries.
- Tricky Words are generated from spelling mistakes and leave the list after 3 correct attempts in a row.
- Spelling uses an on-screen QWERTY keyboard so predictive typing cannot provide the answer.
- Female/Male voice preference in Parent settings, with Female as default and a Test Voice button.
- Maths uses an on-screen number pad rather than the device keyboard.
- Column addition and subtraction rebuilt with place-value cells, dedicated working/exchange boxes, and optional stylus rough-work canvas.
- Practice is the default mode; Show me how provides learning support; Challenge removes place-value headings until help is requested.
- Times tables and division retain traditional practice and explanations.
- MTC-style 25-question challenge retains adjustable timer/timeout behaviour.
- Local progress, stars, results, backup/import and CSV export retained.
